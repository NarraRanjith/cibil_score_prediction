# Contributing

Thanks for your interest in contributing! A few ways to help:

1. Open an issue describing a bug or a feature request.
2. Pick a task marked `good first issue` or `documentation`.
3. Fork the repo and create a descriptive PR.

Development guidelines

- Create a feature branch: `git checkout -b feat/your-feature`
- Keep commits focused and small.
- Add tests for new functionality.
- Ensure linting and tests pass before opening a PR.

Code of conduct

Be respectful and constructive. This project follows a standard code of conduct.
